# NeuraAI Landing Page

A modern and responsive landing page for an AI-based product called NeuraAI.

## 🚀 Project Overview

NeuraAI is a static AI product landing page created using HTML5 and CSS3. 
The website focuses on a clean, modern design and responsive layout.

## ✨ Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- AI product feature cards
- Statistics section
- How It Works section
- About section
- Testimonials section
- Final call-to-action section
- Responsive design for mobile and desktop
- Hover animations and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
